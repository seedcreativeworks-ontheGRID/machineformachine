07 PRINCIPLES how to extend this system
  • 01One signature, everywhere. The clipped corner + reticle bracket is the single identity marker. Don't introduce a second corner treatment — reuse .hud-panel.
  • 02Color means state, not decoration. Cyan = standby/idle. Gold = active/in-progress. Green = complete. Red = critical/time-critical. Never assign these colors arbitrarily.
  • 03Orbitron is for numbers and titles only. It's illegible at body-copy sizes and in long strings — never set instructions or paragraphs in it.
  • 04Motion signals "live," not decoration. Scanlines and pulsing dots should only appear on elements actively updating in real time — a static panel should never scan or blink.
  • 05Glow is a state, not a default. Reserve text/box glow for the current focal readout (master clock, active step). Overusing glow flattens the hierarchy.
